# 📊 Seaborn Practice Notebook

## 📌 Project Overview
This project contains practice examples and visualizations created using the Seaborn library in Python.  
The notebook focuses on statistical data visualization, chart customization, and exploratory data analysis techniques.

It is designed for beginners who want to improve their visualization and EDA skills using Seaborn.

## ▶️ How to Run the Project

### Step 1: Clone Repository
```bash
git clone https://github.com/your-username/seaborn-practice.git
```
### Step 2: Install Required Libraries
```bash
pip install seaborn matplotlib pandas numpy
```
### Step 3: Run Jupyter Notebook
```bash
jupyter notebook
```
### Open:
```bash
Seaborn_Practice.ipynb
```
